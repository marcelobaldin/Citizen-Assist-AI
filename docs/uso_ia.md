## Ferramentas de IA Utilizadas

### Claude (Anthropic) — via Claude Code / Cursor IDE
- **Finalidade:** Assistencia no desenvolvimento do codigo, estruturacao da base de conhecimento e revisao do projeto.
- **Como foi usado:**
  - Geracao da estrutura inicial do projeto seguindo o modelo do repositorio FIAP.
  - Auxilio na escrita da base de conhecimento JSON com informacoes verificadas de fontes oficiais.
  - Desenvolvimento do algoritmo de busca por relevancia (scoring de palavras-chave).
  - Criacao do conjunto de testes automatizados e metricas de avaliacao.
  - Revisao e correcao de erros no codigo.
  - Sugestoes de estruturas de dados adequadas (deque, pilha, grafo, dicionario).

### Processo de Validacao

Todas as informacoes geradas com auxilio de IA foram verificadas manualmente:
1. **Fontes oficiais:** Cada registro da base de conhecimento teve sua fonte verificada em sites .gov.br
2. **Codigo:** Todo o codigo foi revisado, testado e compreendido pelo aluno antes da entrega
3. **Conteudo:** As orientacoes ao cidadao foram comparadas com informacoes dos portais oficiais

### Limitacoes Reconhecidas

- A IA pode gerar informacoes desatualizadas — todas as datas de verificacao estao nos registros
- O algoritmo de busca foi desenvolvido com auxilio de IA mas ajustado manualmente para o contexto brasileiro
- A IA nao substitui a validacao humana, especialmente em informacoes que afetam direitos do cidadao
